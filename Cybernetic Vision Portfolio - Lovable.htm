Your portfolio is now configured for Vercel deployment. Here's how to deploy:

What was set up:

  • vite.config.ts — Nitro preset changed to vercel (Node.js 22 runtime)
  • vercel-build.sh — Builds and prepares the .vercel/output/ directory in Vercel's expected format
  • package.json — Added vercel-build script

Deploy via Vercel CLI (fastest):

# 1. Install Vercel CLI if you haven't
npm i -g vercel

# 2. Build for Vercel
bun run vercel-build

# 3. Deploy
vercel --prebuilt

Deploy via Git (recommended for CI/CD):

  1. Push this repo to GitHub

  2. Import the project on vercel.com/new

  3. In project settings, set:

    • Build Command: bun run vercel-build
    • Output Directory: .vercel/output
    • Framework Preset: Other

  4. Click Deploy
